# Vision-par-ordinateur
# Objectifs

1.Utilisez la détection des valeurs aberrantes pour éliminer les fausses correspondances

2.Appliquez le processus de détection, d'extraction et de mise en correspondance des caractéristiques pour faire correspondre les caractéristiques entre les paires d'images

3.Choisir des algorithmes de détection de caractéristiques appropriés pour des images et des objectifs spécifiques

4.Alignement de paires d'images à l'aide de caractéristiques

5.Calculer une matrice de transformation pour décrire les changements de position et d'orientation de l'objet entre deux images
